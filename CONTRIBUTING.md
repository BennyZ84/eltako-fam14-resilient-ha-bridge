# Contributing

Contributions are welcome, especially:

- verified FAM14/F4HK telegram observations,
- additional actuator profiles,
- safer failover strategies,
- reproducible tests,
- ESP32 TCP↔RS485 firmware examples with clearly documented hardware,
- Home Assistant examples that avoid duplicate sends.

For protocol observations, please include:

1. exact device model,
2. bus/gateway type,
3. EEP if known,
4. raw telegram before/after the action,
5. how the physical state was independently verified.

Do not submit credentials, private keys or personal home addresses.
